# 使用说明

这是一个以 Markdown 为唯一正文来源的个人学习网站。故事和公式来自筛选后的文章；目录、分类和日期归档在构建时生成。

## 阅读与导航

顶栏提供学习路径、知识领域、日期归档和待补录清单。文章页右侧是页内目录，页面底部提供学习顺序中的上一篇、下一篇。搜索框可以检索已发布文章的全文。

文章页的“标记已完成”按钮由你手动控制，不会因为滚动到底自动完成。“标记未完成”可随时撤销。再次打开文章会尝试恢复上次滚动位置，带有章节锚点的链接优先定位该章节。首页“继续阅读”会优先回到最近阅读的文章。

## 进度保存范围

状态只保存在当前浏览器。不同浏览器、设备、隐私模式互相独立。清除网站数据或禁用本地存储会影响保存；站点会显示保存失败提示。新增文章使用新的唯一 ID，不会清空已有文章的完成状态。

## 内容来源

目前已归档 **7 篇**完整寓言：用户提供的粘贴文本补回感受野、池化、参数量与计算量；此前对话补回统计功效、条件概率、贝叶斯定理和全概率公式。完整生成日期无法确认，因此归入“日期不详”；原始月日标签保留但不推测年份，其余 **12** 个已知概念列入待补录清单。导入工具只提取明确选中的助手消息，完整保留正文；不能自动保证内容没有隐私，发布前需要人工审核。

历史 Markdown 保留完整故事、教学内容、公式和章节顺序。网页仅在显示时将 ChatGPT 概念卡片标记转换为概念名称，并整理原文多个一级标题的层级，使页内目录能列出教学章节；这些显示处理不会改写正文源文件。

粘贴文本丢失的标题、分段、制表符表格和示意图排版也只在网页显示时恢复。新归档文章不会自动标记完成；归档数量不代表你已经读过，也不要求一天补完。

本地导出文件、筛选清单和候选正文放入被 Git 忽略的 `.private/`。公开网站仅包含已审核的教学 Markdown。
