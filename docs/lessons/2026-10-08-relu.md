# 今日寓言：负分闸门

城门有一台计分机械，收集各座哨塔传来的消息。有时它送来正分，有时送来大量负分。守卫发现，一座哨塔的强烈正分可以被其他哨塔的负分完全抵消，而重要线索因此被错过。铁匠提出装一道简单的闸门：负分直接归零，正分原样留下。

新装置迅速改变了城门的计算结果。它不需要精巧的齿轮，只要判断一个数是否大于零即可。不过几个月后，铁匠发现一些线路长期送来负值，闸门始终关闭，使这些线路几乎再没有机会贡献消息。

年轻学徒问：“是不是闸门不够聪明？”铁匠摇头：“它从来就不是负责判断消息真假的；它只是在计算链上增加一道明确规则。这道规则很有用，也有代价。”

# 概念揭示：ReLU 激活函数

## 一、它解决什么问题
如果神经网络连续叠加的只有线性层，整体仍可合并成一次仿射变换，难以表示复杂模式。激活函数在层间引入非线性。ReLU（Rectified Linear Unit）是很常见的一种简单激活规则。

## 二、前置概念
**函数**把输入按规则变成输出。**分段函数**对不同输入区间执行不同规则。**导数**直观表示输入小幅改变时输出变化的速度。**非线性**意味着整套映射不能简单写成一个固定矩阵乘法再加偏置。

## 三、公式之前的直觉
输入如果是正数就照抄，如果是负数就写成零。令 \(x\) 为输入，\(\operatorname{ReLU}(x)\) 为函数输出。记号 \(\max(0,x)\) 是从 0 和 \(x\) 两个数字里选择较大的那个，于是：
\[
\operatorname{ReLU}(x)=\max(0,x).
\]

## 四、逐步算例
神经网络某层产生三个数 \([-4,0,3]\)。经过 ReLU 以后得到 \([0,0,3]\)。若后一层直接把三个数相加，激活前为 \(-4+0+3=-1\)，激活后为 \(0+0+3=3\)。正是这类依输入情况改变计算规则的操作，使多层网络不再等价于一层线性计算。

## 五、训练方面的意义与局限
当 \(x>0\)，ReLU 的导数为 1；当 \(x<0\)，导数为 0；在 \(x=0\) 处严格意义下不可导，工程框架会选择一个用于反向传播的约定值。长期处在负区间的单元可能收不到经此激活传递的梯度，出现所谓“死亡 ReLU”。

## 六、AI/OCR 应用
CNN、MLP 等常使用 ReLU。OCR 网络通过卷积提取笔画线索，再用激活函数构造更复杂的模式。但是 Transformer 中也常见 GELU 等激活，所以 ReLU 不是所有架构的唯一选择。

## 七、寓言映射及失效边界
闸门对应 ReLU，正分通过、负分清零对应分段规则；长期关闭对应负区间梯度为零。局限：负数不一定表示坏消息，ReLU 也不理解信号的语义；它只执行数值映射。

## 八、今天真正记住
1. ReLU 就是负值归零、正值保留。
2. 它给线性层之间加入非线性。
3. 正区间的局部斜率是 1，负区间是 0。
4. 可能出现“死亡 ReLU”，不代表它总体不可用。
