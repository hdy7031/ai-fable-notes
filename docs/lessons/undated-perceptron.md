# 今日寓言：看门人的阈值

城门外的车越来越多，新账房虽已能为货车算出分数，但守门人仍不知道哪辆车该优先放行。最初，他碰到高分车就放，碰到低分车就拦，判断全凭心情。城主于是划下一条清晰的红线：“分数达到十就优先入城，否则排普通队。”

规则看似终于清楚了。一日，有辆车因为携带救急药材必须优先通过，但它的货物分数只有九。守门人不敢放行：“铜盘算出来不到十。”另一天，一辆布匹车分数很高，却并不紧急，也被送入优先通道。城主意识到，问题不只是红线放在哪里，也在于铜盘给各种货物多少分。

新账房说：“既然我们有过去哪些车确实该优先通过的记录，不如根据判断错误的情况调整旋钮。也许药材要获得更大的权重，普通布匹的权重应该更小。”守门人又问：“那如果规则没法用一条直线分开两类车怎么办？”新账房看着密密麻麻的记录，知道一台铜盘也许不够。

# 概念揭示：感知机

## 1. 它解决的问题

线性层给出数值，但很多任务要求做出**类别判断**：例如“垃圾邮件还是正常邮件”“字符是 8 还是 B”。最早期的人工神经网络模型之一——感知机——就是把加权分数变成二分类判断。

## 2. 前置概念

**二分类**指只有两个候选类别，例如“通过/不通过”。**阈值**是判断边界：分数不低于它就选一类，否则选另一类。**权重和偏置**来自上一课，负责根据特征计算分数。注意单个感知机在经典定义中使用的是阶跃式判断：小变化可能让输出突然从 0 跳到 1。

## 3. 正式定义与公式

先令 \(x_i\) 为输入的第 \(i\) 个特征；\(w_i\) 为对应权重；\(b\) 为偏置；\(z\) 为加权分数。分数是
\[
z=\sum_i w_ix_i+b.
\]
\(\sum\) 读作“把所有项相加”。然后使用决策规则：
\[
\hat y=\begin{cases}1,&z\ge0\\0,&z<0.\end{cases}
\]
这里 \(\hat y\) 是预测标签，0 和 1 只是两类的数字代号。把判断阈值写为 0 不失一般性，因为任何固定阈值都可以吸收到偏置里。

## 4. 手算一次

假设货车有两个特征：\(x_1=3\) 袋盐、\(x_2=4\) 匹布。给权重 \(w_1=2,w_2=1\)，偏置 \(b=-10\)：
\[
z=2\times3+1\times4-10=0.
\]
由于 \(z\ge0\)，预测为 \(\hat y=1\)，进入优先队列。

如果盐减少一袋，则
\[
z=2\times2+1\times4-10=-2.
\]
现在 \(\hat y=0\)。一个简单的权重变化或输入变化，就可能改变类别。

## 5. 为什么单个感知机有局限

在两个特征的平面中，条件 \(w_1x_1+w_2x_2+b=0\) 是一条直线。单个经典感知机只能用这样的直线把两类样本分开，这叫**线性可分**问题。如果标签布局像棋盘角落互相交错，仅靠一条直线就分不开。最著名的简单例子是 XOR：两个输入相同输出 0，不同输出 1。画出 \((0,0),(0,1),(1,0),(1,1)\) 后，会发现一条直线不能完成正确分割。

这便引出了**多层感知机 MLP**：让多个简单计算单元共同完成更复杂的判断。

## 6. 与 OCR 的联系

OCR 中某个非常简单的特征检测器可以判断“某片区域有没有横线”。复杂字符却不是一个特征就能决定的，需要先组合笔画、局部形状，再识别整体字符。单个感知机可以帮助理解神经元的工作方式，却远不足以构成现代 OCR 模型。

## 7. 寓言对应和边界

货车属性是输入；铜盘旋钮是权重；红线是阈值；守门人输出通过/不通过；旧记录指导调整参数就是学习。局限在于感知机不是具有人类判断力的守门人；输出是确定的类别规则，不天然表示概率。现代深度网络通常使用更便于梯度训练的连续激活函数。

## 8. 今日要点

1. 感知机 = 加权求和 + 二分类决策。
2. 偏置可以移动决策边界。
3. 单个经典感知机只能实现线性决策边界。
4. 多层网络用许多单元组合出更复杂的表示。
