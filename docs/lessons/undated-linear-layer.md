# 今日寓言：可调节的税率盘

港口的老账房退休前留下了一台铜制算盘。商人输入盐和布的数量，机器就给出“是否需要优先卸货”的分数。但最初的齿轮装错了：盐的数量越多，分数涨得越少；布的数量越多，分数反而猛增。码头工人忙得团团转。

新账房发现，铜盘里有两个可以调节的旋钮。第一个决定每袋盐对分数的贡献；第二个决定每匹布的贡献。还有一个不起眼的小旋钮，即使两种货都没有，也可以把最后的分数整体抬高一点。新账房把旧记录铺在桌上，反复观察：旋钮偏向盐时，载盐的大车会得到高分；旋钮偏向布时，载布的小车会得到高分。

一位工人问：“机器算出来的分数究竟代表什么？”

新账房回答：“现在，它只是按照这几个旋钮计算的数。只有等我们把旋钮调得合理，再决定分数如何对应真实行动，它才会成为有用的规则。”

# 概念揭示：线性层、权重与偏置

## 1. 为什么需要它

向量和矩阵可以存数字，矩阵乘法可以按固定规则组合数字。但机器学习还需要**可调整的规则**：根据样本学会哪些特征重要。神经网络的线性层就是这种基础零件。

## 2. 前置概念

**输入特征**是用于计算的数值，例如盐的袋数 \(x_1\) 与布的匹数 \(x_2\)。**权重**是乘在某个输入前面的系数，它控制这个输入贡献有多大。**偏置**是与输入无关、额外加上的常数，可以整体上移或下移输出。**参数**是模型训练时可以改变的这些数值；权重和偏置都属于参数。

## 3. 先有直觉，再有公式

假设盐每袋增加 2 分、布每匹增加 1 分，最后额外加 3 分；那么我们当然按“盐袋数×2 + 布匹数×1 + 3”来算。

现在令 \(x_1,x_2\) 表示两种数量，\(w_1,w_2\) 是两个权重，\(b\) 是偏置，\(z\) 是最终分数，那么
\[
z=w_1x_1+w_2x_2+b.
\]
对于更多特征，可以使用矩阵形式。令 \(x\) 是输入向量，\(W\) 是权重矩阵，\(b\) 是偏置向量，\(z\) 是输出向量。按“每个样本是一行”的约定，可以写成
\[
Z=XW+b.
\]
其中 \(b\) 会按列加到每个样本的结果上。

## 4. 亲手计算

货车有 3 袋盐、4 匹布；设置权重 2 和 1，偏置 3：
\[
z=2\times3+1\times4+3=13.
\]
如果我们把盐的权重改成 4：
\[
z=4\times3+1\times4+3=19.
\]
输入没变，输出却因参数变化而改变。**训练模型的核心之一就是找到更合适的参数**，而不是每次写死人工规则。

## 5. 为什么光堆线性层还不够

有一个容易忽略的结论：如果我们连续做两次纯线性/仿射变换，例如先计算 \(z_1=W_1x+b_1\)，再计算 \(z_2=W_2z_1+b_2\)，那么展开后仍然相当于一次 \(Wx+b\)。所以只不断叠加线性层，并不能表达任意复杂的弯曲决策边界。

神经网络需要在层与层之间加入**非线性激活函数**，才能组合出更丰富的规则。这也解释了为什么会出现 ReLU 等激活函数。

## 6. AI 与 OCR 场景

OCR 网络从图像里提取到一组数字特征后，线性层可以把它们变换成每个候选字符的分数。假设候选字符为 8、B、3，输出三个数字并不直接等于概率；后续通常还需要其他步骤把分数转换成可比较的分类结果。

## 7. 对照寓言与局限

旋钮代表权重和偏置；货物数量是输入；卸货分数是输出；调节旋钮对应训练改变参数。隐喻的局限是：真实神经网络常有成千上万甚至更多参数，也不能仅凭人工直觉逐个调节，必须借助损失函数和优化算法。

## 8. 今天需要记住

1. 线性层做的是“输入按权重组合，再加偏置”。
2. 权重控制某特征的贡献；偏置控制整体平移。
3. 参数可以训练改变，输入相同也可能得到不同输出。
4. 只有线性层层层叠加，表达能力仍有明显限制。
