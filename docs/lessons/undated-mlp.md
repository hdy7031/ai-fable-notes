# 今日寓言：三位学徒如何协作识字？

书院请一名守门人辨认远处旗帜上的文字。他擅长观察横线，却把“王”和“土”经常认错。院长请来第二名学徒专看竖线，又请第三名专看线条相交的位置。三人的发现交给总判官。最初总判官只是把三份记录相加，碰到复杂字形依然常常混淆。

院长让每位学徒不仅报告分数，还要决定自己发现的形状是否足够明显，才把信号传给后面的人。突然，下游判官开始分辨“横线在上、竖线在下”与“横线在下、竖线在上”。这些组合原先被总分淹没，如今却能被一层层保留下来。

总判官说：“我们没有让一个人变得无所不知，而是让许多简单判断按顺序协作。”学徒们也发现，若前面的人误判了，后面再聪明也会被带偏，所有人都需要依据最后结果改进自己的做法。

# 概念揭示：多层感知机 MLP

## 一、它为了解决什么
单个感知机只能用一条线性边界分类，面对复杂的字符组合能力有限。多层感知机（Multi-Layer Perceptron, MLP）把若干计算单元组织成多个层，让前一层产生的特征成为后一层的输入。

## 二、前置知识
**层**是一次有组织的数值变换；**神经元**是对输入做加权组合、加偏置，再经过激活函数的计算单元。这里的“神经元”是工程比喻，并不等同于真实生物神经细胞。**隐藏层**夹在输入和输出之间，它产生的数字并非人工指定的最终标签，因此称为“隐藏”。

## 三、正式定义
MLP 是由多个全连接层及其非线性激活连接而成的前馈神经网络。“全连接”意味着某层每个输出单元可以接收前一层的全部输出；“前馈”意味着本次预测的信息沿层次从输入向输出传播。

设输入向量为 \(x\)，第一层权重为 \(W_1\)，偏置为 \(b_1\)，激活函数记为 \(f\)，最后一层权重为 \(W_2\)、偏置为 \(b_2\)。先形成中间特征 \(h=f(W_1x+b_1)\)，再算输出 \(y=W_2h+b_2\)：
\[
h=f(W_1x+b_1),\qquad y=W_2h+b_2.
\]
这里 \(h\) 是隐藏层结果，而不是最终答案；\(f\) 负责让网络能表现非线性的关系。矩阵维度必须对应，实际实现中也可以把样本写成行向量，公式会相应改变方向。

## 四、手算两个隐藏单元
假设输入 \(x=[2,1]^T\)。第一位学徒算 \(2x_1-x_2=3\)，第二位算 \(-x_1+2x_2=0\)。先用简单规则 \(f(t)=\max(0,t)\)（负数变零、非负不变），得到 \(h=[3,0]^T\)。总判官给第一位权重 1，给第二位权重 -1，偏置 -2，最后分数 \(y=1\times3+(-1)\times0-2=1\)。若规定非负分数预测为类别 1，那么得到类别 1。多层的关键不是数字大，而是中间特征可以组合出新的判断依据。

## 五、AI 的实际意义
在 OCR 中，较早的层可以识别简单笔画线索，较后的层组合成字符形状。但普通 MLP 不会自动利用图像中“相邻像素靠得近”这一空间规律，因此处理图像通常不如专门设计的 CNN 高效。MLP 的计算思想仍广泛出现于 Transformer 的前馈子层。

## 六、寓言映射与局限
每位学徒代表隐藏神经元，总判官代表输出层，逐层提交记录代表前向传播。局限是实际网络不是人工分配“横线学徒”，训练中学到的特征也可能难以直接用自然语言命名。

## 七、今天记住
1. MLP 是按层连接的神经网络，不是一个万能神经元。
2. 隐藏层把已有特征变成新的特征。
3. 非线性激活不可缺，否则多层线性变换可以合并为一层。
4. 预测阶段信息从输入传向输出；训练阶段还要反向计算参数怎样改。
