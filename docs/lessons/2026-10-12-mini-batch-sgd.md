# 今日寓言：潮港的千封校时信

潮港是一座靠海吃饭的小城。每天正午，城中钟楼敲响十二下，港口的引航船便升起蓝旗，告诉外海的商船：现在可以穿过礁石间的狭窄水道了。潮水不会等人，钟声早一刻或晚一刻，都可能让船只误入暗礁。

钟楼由老钟匠闻伯照管。他的钟走得并不十分准，尤其在潮湿的季节，钟摆会慢慢偏离。为了校正它，他请每艘进港的船把自己的计时记录写在信纸上，交给徒弟阿澄。

秋季的第一天，阿澄收到整整一千封信。他想把所有信都核对完，再决定怎样调整钟摆。于是他从清晨抄到深夜，把船名、出发时刻、观测到的钟声偏差一一记入大账簿。等他终于算出一个修正方向，第二天的海风已经改变，港口又积起一千封新信。钟楼只得到一次调整，迟到的钟声却已经耽误了好几艘船。

“全城的信都看完才敢动手，看来我们永远追不上潮水。”阿澄说。

闻伯没有立刻回答，只递给他当天第一封信。信里写着：“钟声比我船上的沙漏慢了三刻。”

阿澄便把钟摆大幅调快。午后，第二封信到了：“钟声比我船上的沙漏快了两刻。”他又急忙把钟摆调慢。第三封信说慢一刻，第四封说快四刻。阿澄的手在钟摆上来回忙碌，钟楼却越来越不稳。

“难道每一封信都不可信？”他沮丧地问。

“每一封都可能包含真消息，”闻伯说，“但船上的沙漏也会受颠簸、潮湿和船员手误影响。你只听一封信，就把偶然的偏差当成了全港的声音。”

第二天，阿澄提出折中的办法：不等一千封全部到齐，也不为一封信就大动钟摆。他把来信打乱顺序，每十封装进一个布袋。取出第一袋，核对十位船员的记录，合起来估计钟摆应怎样调整，做一次小修正；再取第二袋，用**已经调整过的钟**重新衡量这些记录，再修正一次。每袋只需看十封，钟楼便能及时改动，而单个船员的失误也不至于独自左右结果。

起初闻伯担心：“若第一袋恰好全是从北方来的船，它们受同一场风暴影响，结论岂不是也会偏？”

阿澄想了想，把船名写在木签上，充分搅匀，再分进布袋。每完成一轮，他又把木签重新打乱，避免总是让同一批船先发言。遇到最后一袋不足十封，他照样按实际封数求平均，不会为了凑数丢掉来信。

办法奏效了一阵。钟楼能在白天多次微调，进港船只也不再频频抱怨。但一场大雾过后，几袋来信的说法仍然彼此矛盾，钟摆偶尔会被调得稍过头。阿澄着急：“我们不是已经把信分组了吗？为什么还会出错？”

闻伯指着海面说：“分组让我们更快听见众人的意见，却没有把每一袋变成全港的真相。十封信终究只是十封信。袋子太小，容易受偶然因素摆布；袋子太大，又要等很久才能修一次。你还得留心每次究竟改了多少。”

后来，阿澄把每袋信的平均建议、实际调整量和第二天的钟差都记录下来。他发现，分袋大小和每次调整的幅度是两回事：十封信也可以只做一点点修正；一百封信算得再认真，如果调整过猛，钟声照样可能越过准确时刻。他还学会了不把“今天港内几封信的意见一致”当作“所有海域都能准时”的证明——远海船只仍要另行检验。

冬天来临时，港口的蓝旗终于恢复了可信的节奏。阿澄没有得到一只永远准确的神钟，却得到了一套可以不断校准的办法：**从许多记录中随机抽出一小组，汇总这一组的修正方向，调整一次；换一组，再重新计算，再调整。**

闻伯把这套方法写进钟楼的学徒手册。许多年后，研究机器学习的人也遇到了同样的难题：训练数据太多，逐条调整又太吵闹。他们把相似的办法称作**小批量随机梯度下降（Mini-batch SGD）**。

## 一、现实问题：十万张课表图片，怎样让模型及时更新？

上一课讲过梯度下降：先让模型做预测，计算损失；再由反向传播算出梯度，沿负梯度方向调整参数；接着重新预测、重新计算。

问题是：**梯度究竟根据多少条训练数据来算？**

假设我们要训练一个 OCR 模型识别大学课表中的“高数”“英语”“体育”等文字，手上有十万张带正确标签的图片。若每更新一次权重，都要求模型先看完十万张图片，得到整个数据集的平均梯度，虽然方向较稳定，却可能耗时很长，还可能受显存和计算吞吐限制。反过来，若每看一张图就更新一次，速度上更容易及时迈步，但一张模糊、倾斜或标注特殊的图片可能让这一步的梯度与整体方向相差很远。

小批量的想法是：**每次只拿一小组样本，计算这组样本的平均梯度，然后更新一次参数。** 例如每次用 32 张图片，十万张图在一轮中大约能形成 3125 次参数更新，而不是只更新一次；最后一个批次如何处理取决于具体实现。这里的“32”不是数学定律，只是常见的起点之一。

这解决的是训练时**如何组织数据、何时更新参数**的问题，不是替代损失函数，也不是替代反向传播。

## 二、先从零弄懂四个前置概念

### 1. 一条样本：一张图加上它的正确答案

在监督学习中，一条训练样本通常包含输入和标签。例如输入是一张写着“高数”的课表截图，标签是字符串“高数”。模型先给出预测，损失函数衡量预测与标签的差距。**一条样本可以产生一份损失，也可以对模型参数产生一份梯度。**

为了便于手算，后面会把复杂的文字识别简化成“输入一个数字，预测另一个数字”。简化的是任务，不是小批量更新的核心逻辑。

### 2. 梯度：当前参数改一点，损失会怎样变

把模型中的一个权重想成可旋转的旋钮。若当前梯度为正，稍微增大这个权重，损失在局部通常会增大；若梯度为负，稍微增大它，损失在局部通常会减小。梯度告诉我们的是**当前位置附近的变化趋势**，并不保证一次大调整一定更好。

反向传播负责高效算出这些梯度，梯度下降负责利用它们更新权重。这两步仍然是今天方法的基础。

### 3. 平均：让一组样本共同决定方向

假设三条样本分别建议某个参数的梯度为 -4、-2 和 +3。把它们相加再除以样本数，平均梯度就是 -1。这个平均值仍然为负，表示按照这一小组的总体意见，增大该参数更可能降低当前这组数据的损失。

注意：这里**平均的是各样本对参数的梯度**，不一定是直接平均预测值或原始误差。若不同样本的输入不同，同样大小的预测误差可能对应不同大小的参数梯度。

### 4. 一次更新、一个批次、一轮训练

- **Batch（批次）**：一次更新时拿来计算梯度的一组样本。
- **Batch size（批大小）**：这组里有多少条样本，例如 2、16 或 32。
- **Iteration / step（迭代或更新步）**：通常指完成一个批次的前向计算、反向传播和一次参数更新。
- **Epoch（轮次）**：通常指按某种遍历方案，让训练集里的样本各参与一次训练；一轮里可以有很多次更新。

例如 100 条样本、每批 20 条，且一轮中每条只使用一次，则一轮有 5 个批次、通常对应 5 次更新。**一轮训练不等于一次参数更新。** 若最后一批不满，实际批次数还要按是否保留尾批来计算。

## 三、正式定义：全量、单样本与小批量究竟差在哪儿？

先定义符号，再写公式。

- \(N\)：训练集中样本总数。
- \(i\)：某一条样本的编号，范围为 1 到 \(N\)。
- \(x_i\)：第 \(i\) 条样本的输入；\(y_i\)：它的正确标签。
- \(\boldsymbol{\theta}\)：模型所有可训练参数组成的向量，例如大量权重和偏置。
- \(f_{\boldsymbol{\theta}}(x_i)\)：使用当前参数，对第 \(i\) 条输入做出的预测。
- \(\ell(\,\cdot\,,\,\cdot\,)\)：单条样本的损失函数，比较预测与正确答案。
- \(L(\boldsymbol{\theta})\)：整个训练集的平均损失。
- \(\nabla_{\boldsymbol{\theta}}\)：对所有参数求偏导，并把结果组成梯度向量。
- \(t\)：第几次更新；\(\boldsymbol{\theta}_t\) 是更新前的参数。
- \(B_t\)：第 \(t\) 次更新选中的样本编号集合；\(|B_t|\) 是这个批次实际包含的样本数。
- \(\eta\)：学习率，决定每次沿梯度方向调整的幅度。
- \(\sum\)：求和符号，意思是把指定样本的结果加起来。

整个训练集的平均损失写作：

\[
L(\boldsymbol{\theta})
=\frac{1}{N}\sum_{i=1}^{N}
\ell\!\left(f_{\boldsymbol{\theta}}(x_i),y_i\right).
\]

**全批量梯度下降（Full-batch Gradient Descent）**每次根据全部 \(N\) 条样本求平均梯度，再更新参数。它对当前完整训练集损失给出精确梯度，但每次更新都需要遍历全体训练样本。

**单样本随机梯度下降（经典的 SGD）**每次随机选一条样本，用这一条样本的梯度更新。单步计算便宜，但梯度波动通常较大。

**小批量 SGD（Mini-batch SGD）**每次选出一小组样本，取这组样本的平均梯度，再更新。它的核心公式是：

\[
\boxed{
\boldsymbol{\theta}_{t+1}
=\boldsymbol{\theta}_t
-\eta\,\frac{1}{|B_t|}
\sum_{i\in B_t}
\nabla_{\boldsymbol{\theta}}
\ell\!\left(f_{\boldsymbol{\theta}_t}(x_i),y_i\right)
}
\]

把公式逐句翻译成人话：

1. 用**当前参数** \(\boldsymbol{\theta}_t\) 处理这批样本，得到每条样本的损失与梯度。
2. 把批次内的梯度相加，除以实际样本数 \(|B_t|\)，得到**这批样本的平均梯度**。
3. 用“旧参数减去学习率乘以平均梯度”得到新参数 \(\boldsymbol{\theta}_{t+1}\)。
4. 换下一批时，必须用**更新后的参数**重新计算梯度，不能把旧批次的梯度原样套用。

这里有个命名上的细节：严格区分时，SGD 原本指每次用一条样本；但在实际深度学习框架和工程交流中，人们也经常把“用 mini-batch、每步直接沿平均梯度更新”的优化方式统称为 SGD。**“随机”主要来自样本的随机抽取或打乱顺序，并不是参数随意乱改。**

若样本从整个训练集中均匀随机抽取，在参数固定时，小批量平均梯度是全量梯度的一个合理随机估计；它有波动，不代表每一步都会让整个训练集损失下降。

## 四、完整手算：四条样本、两次更新、走完一个 Epoch

真实 OCR 网络可能有数百万个参数，无法在纸上逐个计算。我们先训练一个只有**一个权重**的微型模型，亲手完成一轮小批量 SGD。计算过程与大网络的更新思想相同。

### 1. 数据和模型

四条样本分别是：

| 样本编号 | 输入 \(x_i\) | 正确答案 \(y_i\) |
|---|---:|---:|
| 1 | 1 | 2 |
| 2 | 2 | 4 |
| 3 | 3 | 6 |
| 4 | 4 | 8 |

这些数据符合“正确答案等于输入的两倍”。我们的模型却暂时不知道那个“2”，只会用一个可学习的权重 \(w\) 乘输入。

在写公式前，把新符号说明白：

- \(w\)：模型唯一的可训练权重，初始值设为 \(w_0=0\)。
- \(\hat y_i\)：模型对第 \(i\) 条样本的预测值；它等于 \(w\) 乘以输入 \(x_i\)。
- \(\ell_i(w)\)：第 \(i\) 条样本的损失；使用“预测减正确答案”的平方，再乘以二分之一。
- \(g_i(w)\)：第 \(i\) 条样本对权重 \(w\) 的梯度，也就是该损失对 \(w\) 的导数。
- \(\eta=0.05\)：本例固定学习率。
- 批大小设为 2，第一批是样本 1、2，第二批是样本 3、4。为方便演算，我们明确给出这一轮的分组；真实训练常先打乱样本顺序。

于是模型、损失和梯度分别是：

\[
\hat y_i=wx_i,\qquad
\ell_i(w)=\frac12(wx_i-y_i)^2,
\]

\[
g_i(w)=\frac{\mathrm d\ell_i}{\mathrm dw}
=(wx_i-y_i)x_i.
\]

最后一式来自链式法则：平方误差对括号内的误差求导，再乘以误差对 \(w\) 的导数 \(x_i\)。这正是前面“链式法则—反向传播—梯度下降”三课连接起来的地方。

### 2. 第一个批次：样本 1 和 2

当前权重为 \(w_0=0\)。

样本 1：预测 \(0\times1=0\)，误差 \(0-2=-2\)，梯度为

\[
g_1(0)=(-2)\times1=-2.
\]

样本 2：预测 \(0\times2=0\)，误差 \(0-4=-4\)，梯度为

\[
g_2(0)=(-4)\times2=-8.
\]

这批只有两条样本，因此平均梯度是

\[
\bar g_{B_0}=\frac{-2+(-8)}2=-5.
\]

现在**真正更新一次权重**：

\[
w_1=w_0-\eta\bar g_{B_0}
=0-0.05\times(-5)
=\boxed{0.25}.
\]

第一批结束，权重从 0 变成 0.25。不要忘记：这是**第一次更新**，还没有走完一轮数据。

### 3. 第二个批次：样本 3 和 4

关键来了：此时必须用**新权重 \(w_1=0.25\)**，不能继续用旧的 0。

样本 3：预测 \(0.25\times3=0.75\)，正确答案 6，误差是 \(0.75-6=-5.25\)。梯度：

\[
g_3(0.25)=(-5.25)\times3=-15.75.
\]

样本 4：预测 \(0.25\times4=1\)，正确答案 8，误差是 \(1-8=-7\)。梯度：

\[
g_4(0.25)=(-7)\times4=-28.
\]

第二批平均梯度：

\[
\bar g_{B_1}
=\frac{-15.75+(-28)}2
=-21.875.
\]

第二次更新：

\[
w_2=0.25-0.05\times(-21.875)
=\boxed{1.34375}.
\]

四条样本都参与过这一轮训练，所以现在完成了**1 个 Epoch、2 个批次、2 次参数更新**。注意：两个批次的平均梯度不同，一方面因为样本不同，另一方面因为第二批计算时权重已经变了。

### 4. 训练真的改善了吗？用全体四条样本检查

我们先定义用于检查的量：\(L(w)\) 是四条样本的**平均损失**，也就是四个单样本损失相加后除以 4。由于这四条样本满足 \(y_i=2x_i\)，可把它化简为：

\[
L(w)=\frac14\sum_{i=1}^{4}\frac12(wx_i-y_i)^2
=\frac{30}{8}(w-2)^2.
\]

其中 30 来自 \(1^2+2^2+3^2+4^2\)，8 来自四条样本的平均以及损失公式里的二分之一。

训练前 \(w_0=0\)：

\[
L(0)=\frac{30}{8}(0-2)^2=\boxed{15}.
\]

两次更新后 \(w_2=1.34375\)：

\[
L(1.34375)
=\frac{30}{8}(1.34375-2)^2
=\boxed{1.614990234375}.
\]

| 时刻 | 已看过的批次 | 权重 | 全数据平均损失 |
|---|---|---:|---:|
| 训练开始 | 无 | 0 | 15 |
| 第一批后 | 样本 1、2 | 0.25 | 约 11.4844 |
| 第二批后 | 样本 3、4 | 1.34375 | 约 1.6150 |

这说明**本例**的训练集损失明显下降了；但不能因此断言小批量 SGD 在所有问题中每一步都下降。换一组样本、不同的初始权重或更大的学习率，单步损失可能反而上升。

再看一个容易混淆的数字：在初始 \(w=0\) 时，四条样本的梯度依次为 -2、-8、-18、-32，全量平均梯度是 \((-2-8-18-32)/4=-15\)。而我们第一小批只看到样本 1、2，得到 -5。**小批量不是算错了梯度，而是用部分样本估计全量方向。** 两种方法每轮更新次数不同，不能只比较单次更新后的损失就断言谁一定更快。

## 五、在神经网络和 OCR 中具体怎样用？

想象一个课表 OCR 识别器：输入是裁剪后的文字图片，输出是字符序列。模型内部可能有 CNN、Transformer 等网络层，每层都包含需要训练的权重。

一次典型的 mini-batch SGD 训练步骤是：

1. 从训练集选出一批图片及其正确文本标签，例如 32 张；通常在每个 Epoch 开始前打乱训练样本顺序。
2. **前向传播**：把这批图片送入模型，得到每张图片的预测结果。
3. **计算损失**：依据标签和任务采用适合的损失函数，例如某些字符分类任务用交叉熵，变长文字识别任务可能用 CTC；在框架里通常对批次损失做平均或按指定规则归一化。
4. **反向传播**：从批次损失计算各层参数的梯度。
5. **SGD 更新**：按学习率与梯度调整参数；再读取下一批，重复以上过程。

它的价值不仅是“少看一点数据”。在 GPU 上，把多张图片组成张量一起计算，往往能比逐张处理更充分地利用并行计算；但批次太大也可能耗尽显存。对于文字图像，宽高不一、文本长度不同，还可能需要缩放、补齐或按形状分组，才能高效组批。

**批大小和学习率是两个独立但相互影响的选择。** 批次较小，单次占用的显存通常较少、梯度波动较大；批次较大，梯度估计通常更稳定，但单次计算和内存需求可能增加，而且每个 Epoch 的更新次数减少。不存在对所有 OCR 模型都最优的固定批大小。训练时还要观察验证集表现，而不能只看训练损失。

最后一个细节：如果代码把每条样本的损失**求和**而不是**求平均**，那么批大小改变时，梯度的数值尺度也可能跟着改变。今天的手算和主公式都明确使用了**批内平均梯度**，这样更便于比较不同批大小。

## 六、把寓言映射回来，也看清比喻的边界

| 潮港故事 | 机器学习中的对应 |
|---|---|
| 一艘船寄来一封校时信 | 一条训练样本提供一份信息 |
| 一千封信都核对完才调整一次 | Full-batch：遍历全体数据再更新 |
| 每来一封信就立刻调整 | 单样本 SGD：每条样本更新一次 |
| 每十封装一袋，汇总后调整 | Mini-batch SGD：按批次平均梯度更新 |
| 重新搅匀木签、分袋 | 打乱样本，降低固定顺序带来的偏差 |
| 每调一次钟，再衡量下一袋 | 用新参数对下一批重新计算梯度 |
| 钟摆调整过猛会失准 | 学习率过大可能造成震荡或发散 |

**比喻的边界同样重要。** 船员信中的“早了几刻、晚了几刻”是观测误差，机器学习真正用于更新的却是**损失对参数的梯度**，两者不是同一个量。不同图片对同一个权重的影响，还要经过神经网络的计算链和反向传播才能得出。

此外，港口的钟只有少数可调零件，而真实神经网络可能有成千上万个参数；各参数的梯度方向可以不同。随机分袋能缓解单条记录的偶然性，却不能消除错误标签、系统性数据偏差或模型能力不足。即使训练集上的钟声越来越准，也仍需用未参与训练的样本检验泛化效果。

## 七、今天真正要记住的四点

1. **Batch 是一组样本，Batch size 是组内样本数，Iteration 是一次更新，Epoch 通常是遍历一轮训练集。** 一个 Epoch 往往包含许多次更新。
2. **Mini-batch SGD 用一小批样本的平均梯度更新参数。** 它在“全量计算太重”和“单样本梯度太吵”之间取得折中，但每批梯度只是全量梯度的估计。
3. **每次更新后必须用新参数处理下一批。** 本例两批分别得到平均梯度 -5 和 -21.875，使权重从 0 更新到 0.25，再到 1.34375。
4. **批大小不等于学习率；训练集损失下降也不等于泛化能力提高。** 批大小影响梯度估计与计算资源，学习率控制更新幅度。

**自然前置复习：** 梯度下降；计算图与反向传播。
