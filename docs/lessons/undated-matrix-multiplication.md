# 今日寓言：抄账师的捷径

港口有两种货：盐和布。账房每天要给三位商人算两种税：进城税按盐每袋两枚、布每匹一枚；仓储税按盐每袋一枚、布每匹三枚。最初，抄账师把每一种税的规则写在长长的纸条上，每来一位商人就重新读一遍，再挨个乘加。

新学徒把每位商人的货物数量排成两格，把两种税的规则也排成整齐的两列。账房一下清爽了：只需要让“每位商人的数量”逐项碰上“每种税的费率”，再加总即可。一天夜里，老抄账师匆忙把表格旋转过来，算出的税款全乱了。

学徒指着表格说：“并不是随便两张表都能相乘。前一张表的货物种类，必须和后一张表的收费种类一一对得上。匹数不能拿去当袋数。”

老抄账师突然意识到，过去所谓繁杂的乘加，其实是同一套规则对很多对象重复执行；而表格的位置与大小决定了规则能否正确套上去。

# 概念揭示：矩阵乘法

## 1. 它解决什么问题

当很多样本都需要执行同一组“各项相乘再求和”的计算时，逐条手算既慢又容易混淆。矩阵乘法把这些重复计算组织成一个统一运算。它是神经网络线性层最常见的计算骨架。

## 2. 必须知道的前置

**向量**是一组有顺序的数；**矩阵**是数字表。**点积**是两个等长向量对应元素相乘再求和。例如 \([2,3]\) 与 \([4,5]\) 的点积是 \(2\times4+3\times5=23\)。如果分别代表货物数量与单价，点积就相当于总价。

## 3. 正式定义

矩阵乘法中，结果第 \(i\) 行、第 \(j\) 列的数字，来自**左矩阵第 \(i\) 行**与**右矩阵第 \(j\) 列**的点积。

先约定：左矩阵 \(A\) 有 \(m\) 行、\(n\) 列；右矩阵 \(B\) 有 \(n\) 行、\(p\) 列。它们共同的 \(n\) 保证相乘时每一项都有对应数字。结果矩阵 \(C\) 有 \(m\) 行、\(p\) 列，记作
\[
C=AB,\qquad C_{ij}=\sum_{k=1}^{n}A_{ik}B_{kj}.
\]
这里 \(i\) 是行号，\(j\) 是列号，\(k\) 用来逐个遍历并累加对应元素；符号 \(\sum\) 表示把这些乘积加起来。

## 4. 手算货税

假设两个商人的货物分别为 2 袋盐、3 匹布，以及 1 袋盐、4 匹布。写成
\[
A=\begin{bmatrix}2&3\\1&4\end{bmatrix}.
\]
两种税的规则：进城税是 \([2,1]\)，仓储税是 \([1,3]\)。把每一种税放在一列：
\[
B=\begin{bmatrix}2&1\\1&3\end{bmatrix}.
\]
第一位商人的进城税：\(2\times2+3\times1=7\)。仓储税：\(2\times1+3\times3=11\)。

第二位商人的进城税：\(1\times2+4\times1=6\)。仓储税：\(1\times1+4\times3=13\)。

于是
\[
AB=\begin{bmatrix}7&11\\6&13\end{bmatrix}.
\]
左表形状 \(2\times2\)，右表也是 \(2\times2\)，结果 \(2\times2\)。但形状相同并不代表可以随便倒置顺序：通常 \(AB\neq BA\)。

## 5. AI 中的应用

如果每个样本有 3 个输入特征，我们想算出 2 个新特征，就可以让一个形状为“样本数 × 3”的矩阵，乘上形状为“3 × 2”的权重矩阵，得到“样本数 × 2”的结果。神经网络就是靠许多类似的变换，把原始输入逐渐转成有用的内部表示。

## 6. 寓言映射与限制

商人是样本，盐布数量是输入特征，税率表是变换规则，两种税额是输出特征；货物种类必须对齐，对应矩阵内侧维度必须一致。局限是，税率固定而模型权重会通过训练改变；矩阵乘法只是一种线性计算，不自动拥有理解力。

## 7. 记住这四点

1. 点积就是对应相乘后求和。
2. 矩阵乘法把多组点积一次性组织起来。
3. \((m\times n)(n\times p)\) 才能得到 \(m\times p\)。
4. 在神经网络中，矩阵乘法负责大批量地执行可学习的数值变换。
