# 今日寓言：镜海城的碎窗议会

镜海城有一座奇特的望海楼。楼顶嵌着一面巨大的彩色玻璃窗，窗上绘着整座海湾：白帆、礁石、灯塔和蜿蜒的防波堤。每当暴风雨将至，守城人就要从这幅画里找出一条安全航道。可是窗太大了，站在楼下的人只能看见一团混杂的颜色，谁也说不清哪里是灯塔，哪里是浪花。

老工匠提出过一个办法：让学徒拿着小木框，从左到右、从上到下，一格格寻找熟悉的花纹。第一格像帆角，第二格像浪尖，第三格像礁石边缘。把邻近格子的线索慢慢拼起来，确实能认出一些东西。可遇到一艘横跨许多格的大船，或一道从远处延伸到灯塔的航道，学徒就得不断传话，等消息穿过整幅窗，风暴也许已经到了。

这时，年轻的制图师阿澜提出了一个听起来很冒险的主意：既然大家看不清整面窗，不如先把它切成大小一致的方形玻璃片，每片交给一位信使。信使不必携带所有颜色，只需把自己看到的图案压缩成一张短卡片。随后，所有信使围坐一桌，彼此交换线索。

“这样岂不是更乱？”守城人问，“一片蓝色玻璃，可能来自天空，也可能来自海面。离开原来的位置，谁还认得它？”

阿澜便在每张卡片背面加上一枚位置印记：第几行、第几列、离窗角有多远。这样，颜色相近的两片玻璃虽然看着相似，却不再被当成同一个地方。

第一次试验，议会仍然失败了。来自左上角的信使喊：“我看到一条白线！”右下角的信使也喊：“我也看到白线！”众人忙着记录所有消息，却没有人知道该听谁的。阿澜意识到，议会缺少的不是消息，而是**带着问题挑选消息的办法**。

第二次，她让每位信使先写下自己最想知道的事，再向其他卡片寻找线索。看到帆角的信使想知道“船身在哪里”，便优先听取那些图案能与帆角相接的卡片；看到灯塔的信使想知道“航道是否通畅”，便把注意力投向海面与礁石之间的片段。两块玻璃即使相隔很远，也可以直接交流，不必沿着相邻格子一级一级传话。

然而，议会依旧有一个难题：每个人都忙于理解自己那片玻璃，谁来回答守城人的最终问题——“这张图里，船能否安全入港？”

阿澜于是请来一位不负责任何玻璃片的记录官。记录官拿着一张空白卡片，坐在所有信使之间，只负责询问、汇总和作出最终判断。第一轮会议，他只知道远处有帆；第二轮会议，他听说帆旁有船身，船身前有礁石；又经过几轮，记录官终于能说出：“这不是一艘驶向港口的商船，而是一艘正在绕开暗礁的救援船。东侧航道必须关闭，西侧可以通行。”

风暴到来那晚，城门第一次没有因一幅过于庞大的画而争论不休。守城人却仍不放心：“你们只是把画切碎了，怎么反而看见了整张画？”

阿澜把议会留下的卡片摊开：每片玻璃有自己的图案摘要和位置印记；每张卡片可以按需要向所有其他卡片取证；一位专门的记录官把全局线索聚合起来。她说：“秘密不是切碎，而是**把图像变成一组能够相互交流的片段**。”

许多年后，计算机研究者把这套思想搬进视觉模型：先把图像切成小块，再像处理一串词语那样处理这些小块，借助 Transformer 的自注意力学习它们之间的关系。这种架构便是今天的主角——**Vision Transformer，简称 ViT，视觉 Transformer**。

## 一、现实问题：为什么不直接把整张图送进 Transformer？

前面已经认识两类能力不同的模型：

- **CNN（卷积神经网络）**：用卷积核在局部窗口里寻找边缘、纹理和形状；多层堆叠后，感受野逐渐扩大。它天然擅长利用图像的局部性。
- **Transformer**：把输入当成一串向量，通过注意力计算不同位置之间的联系。它擅长在一次注意力运算中建立远距离依赖。

问题是：文本本来就可以分成词或 token；一张图像却通常是高、宽、通道构成的三维数组。

假设一张 RGB 图像大小为 $224\times224$，每个像素有红、绿、蓝三个数。如果把每个像素都当作一个 token，就会得到 $224\times224=50\,176$ 个 token。普通全局自注意力要计算每对 token 的关联，注意力矩阵的元素数约为 $50\,176^2$，超过 25 亿，代价非常高。

ViT 的关键第一步，是**不把每个像素当作一个词，而是把一小块图像当作一个词**。这样既保留了图像的局部内容，也让 Transformer 有机会在较短的序列上工作。

注意：把图像分块并不等于理解图像。真正学习图像关系的是后面的可训练投影、位置表示和 Transformer 编码器。

## 二、从零理解：Patch、Token 和 Embedding 是什么？

### 1. Patch：一块图像，不是一个像素

设原始图像的高、宽分别为 $H,W$，通道数为 $C$。每个正方形 Patch 的边长为 $P$ 个像素。为了先讲清基本情形，假设 $H,W$ 都能被 $P$ 整除，而且各块不重叠。

那么 Patch 数量是：

$$
N=\frac{H}{P}\times\frac{W}{P}
$$

例如 $224\times224$ 的图像采用 $16\times16$ 的 Patch，就得到：

$$
N=\frac{224}{16}\times\frac{224}{16}=14\times14=196
$$

因此，一幅图从 50,176 个像素位置变成 196 个 Patch 位置。**每个 Patch 内仍包含完整的像素数据**，只是暂时把这些数据打包在一起。

### 2. Flatten：把小方块排成一行数字

每个 Patch 的形状是 $P\times P\times C$。把其中的数字按固定顺序排列，得到一个长度为 $P^2C$ 的向量，这叫展平（flatten）。

对于 $16\times16$ 的 RGB Patch，长度是：

$$
P^2C=16\times16\times3=768
$$

展平只是改变数据的排列方式，本身不学习任何特征，也没有丢弃像素值。需要注意的是：展平后的线性序列不再显式呈现二维邻接结构，模型必须借助投影、位置编码及训练去学习有用的空间关系。

### 3. Patch Embedding：把像素数据翻译成模型能交流的向量

Transformer 内部使用固定宽度 $D$ 的 token 向量。如果 Patch 展平后的长度与 $D$ 不同，就通过一个可训练的线性层完成映射。

先认识符号：$x_i$ 是第 $i$ 个 Patch 展平后的行向量；$E$ 是可训练权重矩阵；$b$ 是偏置；$e_i$ 是映射后的 Patch embedding。矩阵 $E$ 的形状是 $(P^2C)\times D$，偏置 $b$ 的长度是 $D$。

$$
e_i=x_iE+b
$$

它与前面学过的线性层没有本质区别：输入是数字，权重决定如何组合数字，输出是模型学习到的特征。**Embedding 不是给每块图片贴一个人工标签，而是训练出来的一种数值表示。**

实现上，也可以用卷积核大小为 $P$、步幅为 $P$ 的卷积完成等价的非重叠 Patch 线性投影；但“用卷积实现投影”不代表 ViT 的后续主体变成了 CNN。

## 三、Patch 变成序列以后，还缺什么？

### 1. 位置：同样的蓝色，可能是天空，也可能是海面

假设两块图像的颜色很相似，一块来自左上角，一块来自右下角。若只把 Patch embedding 送入没有位置机制的自注意力，模型就缺乏区分它们原始空间位置的直接依据。

因此，ViT 会为每个序列位置提供位置向量。这里用 $p_i$ 表示第 $i$ 个位置的向量，$e_i$ 表示 Patch embedding，$z_i$ 表示实际送入编码器的输入 token：

$$
z_i=e_i+p_i
$$

位置向量与 Patch embedding 的维度必须一致，才能逐元素相加。经典 ViT 通常采用可学习的绝对位置嵌入；这与上一讲介绍的正弦位置编码属于不同实现，不应混为一谈。

### 2. 分类记录官：[CLS] token

如果目标是“这张图像属于哪一类”，仅有 Patch token 还不够方便。经典 ViT 在序列最前面添加一个可学习的分类 token，常写作 [CLS]。它不对应任何真实图像块，而是一个专门用于聚合全局信息的向量。

加入 [CLS] 后，原本 $N$ 个 Patch token 变成 $N+1$ 个 token。把 [CLS] 的可学习初始向量记作 $e_{\mathrm{cls}}$，把所有位置向量排在一起，整个输入序列可写成：

$$
Z_0=[e_{\mathrm{cls}};e_1;e_2;\ldots;e_N]+E_{\mathrm{pos}}
$$

这里的方括号表示**沿序列维度拼接**，不是向量求和；$E_{\mathrm{pos}}$ 包含 [CLS] 和所有 Patch 位置的向量。

在 $224\times224$、Patch 边长为 16 的例子里，序列长度就是 $196+1=197$。如果隐藏维度 $D=768$，输入编码器的张量形状为 $197\times768$；有批次时还要在最前面加批次维度。

## 四、正式定义：Vision Transformer 究竟是什么？

**Vision Transformer（ViT）是一类将图像表示为 Patch token 序列，再利用 Transformer 编码器学习视觉表征的神经网络架构。** 在经典图像分类版本中，模型通常把最后一层 [CLS] token 的表示送入分类头，输出各类别的分数。

逐句拆开：

**“将图像表示为 Patch token 序列”**：先分块、展平、线性投影，再加入位置表示。它解决的是“二维像素怎样变成 Transformer 输入”的问题。

**“利用 Transformer 编码器学习视觉表征”**：每层通过多头自注意力让不同 Patch 交换信息，再由前馈网络对每个 token 的特征做非线性变换。残差连接和 LayerNorm 帮助训练。它解决的是“局部片段怎样形成上下文相关表示”的问题。

**“利用 [CLS] 做分类”**：让一个特殊 token 在多层交互后承载用于分类的信息。它解决的是“如何从一组 token 得到整张图像的类别”的问题。并非所有视觉 Transformer 都必须使用 [CLS]；检测、分割、OCR 等任务往往使用其他输出头或特征聚合方式。

经典 ViT 的一个编码器块，可以概括为以下两步。这里 $Z$ 表示输入 token 矩阵，$\mathrm{LN}$ 表示 LayerNorm，$\mathrm{MSA}$ 表示多头自注意力，$\mathrm{MLP}$ 表示逐 token 的前馈网络，撇号表示中间结果：

$$
Z' = Z+\mathrm{MSA}(\mathrm{LN}(Z))
$$

$$
Z_{\mathrm{out}}=Z'+\mathrm{MLP}(\mathrm{LN}(Z'))
$$

这是一种常见的 Pre-LN 写法。残差加法要求分支输出与输入形状相同。不同模型实现可能调整归一化位置或其他细节，不能把这一组公式误认为所有 ViT 变体都完全相同。

## 五、亲手算一遍：一幅 $4\times4$ 小图如何走进 ViT？

为了能逐项核对，我们故意把图像、Patch 和隐藏维度缩到极小。**以下权重和位置向量都是教学设定，不是从真实数据训练得到的参数**；也省略了真实编码器中的多头、归一化和 MLP，只计算一次简化的自注意力。

### 第一步：把图像切成四块

设图像只有一个灰度通道，像素值只取 0 或 1：

$$
X=
\begin{bmatrix}
1&0&0&1\\
1&0&0&1\\
1&1&0&0\\
1&0&1&1
\end{bmatrix}
$$

采用 $2\times2$ Patch，按“左上、右上、左下、右下”的顺序切开。四块分别是：

$$
A=\begin{bmatrix}1&0\\1&0\end{bmatrix},
\quad
B=\begin{bmatrix}0&1\\0&1\end{bmatrix},
\quad
C=\begin{bmatrix}1&1\\1&0\end{bmatrix},
\quad
D=\begin{bmatrix}0&0\\1&1\end{bmatrix}
$$

把每块按行展平，得到四个长度为 4 的行向量：

$$
x_A=[1,0,1,0],\quad x_B=[0,1,0,1],\quad
x_C=[1,1,1,0],\quad x_D=[0,0,1,1]
$$

### 第二步：用同一个线性层压缩每个 Patch

我们把隐藏维度设为 $D=2$，并令偏置为零。投影矩阵取：

$$
E=
\begin{bmatrix}
1&0\\
0&1\\
1&0\\
0&1
\end{bmatrix}
$$

这表示第一个输出维度把展平向量的第 1、3 个数字相加，第二个输出维度把第 2、4 个数字相加。例如左上角：

$$
e_A=[1,0,1,0]E=[1+1,\;0+0]=[2,0]
$$

其他三块同理：

$$
e_B=[0,2],\qquad e_C=[2,1],\qquad e_D=[1,1]
$$

四个 Patch 现在都变成长度为 2 的 token。请注意：这种二维投影可能丢失细节，因为四维输入被压缩到二维；真实模型能否保留任务所需信息，取决于维度、可训练权重和训练数据。

### 第三步：加上位置，并插入 [CLS]

假设四个位置向量依次设为：

$$
p_A=[0,0],\quad p_B=[1,0],\quad
p_C=[0,1],\quad p_D=[1,2]
$$

相加后，四个实际输入 token 是：

$$
z_A=[2,0],\quad z_B=[1,2],\quad
z_C=[2,2],\quad z_D=[2,3]
$$

再在最前面加入一个初始向量为 $[1,0]$ 的 [CLS] token；为简化计算，它的位置向量设为 $[0,0]$。于是整个序列矩阵为：

$$
Z_0=
\begin{bmatrix}
1&0\\
2&0\\
1&2\\
2&2\\
2&3
\end{bmatrix}
$$

它有 5 行，每行 2 个数字；第 1 行是 [CLS]，后 4 行依次对应四个 Patch。

### 第四步：让 [CLS] 向所有 token 询问信息

回顾自注意力：Query（查询）代表当前 token 想找什么；Key（键）代表其他 token 提供怎样的匹配线索；Value（值）代表被选中后实际汇入的信息。

标准缩放点积注意力的形式是：

$$
\mathrm{Attention}(Q,K,V)=
\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

其中 $Q,K,V$ 分别是查询、键、值矩阵，$d_k$ 是键向量的维度，$\sqrt{d_k}$ 是缩放因子；softmax 对每一行的匹配分数归一化，使该行权重非负且总和为 1。

为了算得直观，我们令这一层的三个投影矩阵都是 $2\times2$ 单位矩阵，所以 $Q=K=V=Z_0$，并且 $d_k=2$。这里只计算 [CLS] 这一行；它的 Query 是 $q_{\mathrm{cls}}=[1,0]$。

与五个 Key 分别做点积，再除以 $\sqrt{2}$，得到：

$$
s=\frac{[1,\;2,\;1,\;2,\;2]}{\sqrt{2}}
\approx[0.7071,\;1.4142,\;0.7071,\;1.4142,\;1.4142]
$$

softmax 先取指数，再除以指数之和。两种不同分数的指数近似为：

$$
e^{0.7071}\approx2.0281,\qquad
e^{1.4142}\approx4.1133
$$

由于低分出现两次、高分出现三次，分母是：

$$
S=2(2.0281)+3(4.1133)\approx16.3960
$$

因此 [CLS] 分配给五个 token 的注意力权重约为：

$$
a=[0.12370,\;0.25087,\;0.12370,\;0.25087,\;0.25087]
$$

核对一下：$2\times0.12370+3\times0.25087\approx1$。分数较高的 token 权重更大，但**注意力权重不是“某块图像属于某类”的概率**，它只描述这一层这一查询如何混合 Value。

### 第五步：计算 [CLS] 收集到的新信息

Value 仍是 $Z_0$ 的五行。把每一行乘以对应注意力权重再相加，得到 [CLS] 的注意力输出：

$$
o_{\mathrm{cls}}
=0.12370[1,0]+0.25087[2,0]+0.12370[1,2]
+0.25087[2,2]+0.25087[2,3]
$$

第一维为 $2(0.12370)+6(0.25087)\approx1.7526$；第二维为 $2(0.12370)+5(0.25087)\approx1.5017$。因此：

$$
o_{\mathrm{cls}}\approx[1.7526,\;1.5017]
$$

这一步展示了**一个特殊 token 如何直接汇总全图多个位置的信息**。真实 ViT 会把注意力输出再经过输出投影、残差连接、归一化、MLP，并重复多个编码器块；不能把这里的 $o_{\mathrm{cls}}$ 当成真实 ViT 的最终隐藏状态。

### 第六步：用一个教学分类头作出预测

假设我们直接拿刚算出的二维向量做演示，设置两个类别：“含目标”和“不含目标”。分类头采用单位矩阵、零偏置，于是两个类别的 logits（未归一化分数）分别是 $1.7526$ 和 $1.5017$。

将这两个数送入 softmax，第一个类别的概率约为：

$$
P(\text{含目标})
=\frac{e^{1.7526}}{e^{1.7526}+e^{1.5017}}
=\frac{1}{1+e^{-0.2509}}
\approx0.5624
$$

也就是约 56.24%。这是**玩具模型的计算结果，不是任何真实图像的可信识别率**。真正的分类头权重需要训练，模型输出概率还可能需要校准。

把全过程串起来，就是：图像 → Patch → 展平 → 线性投影 → 加位置 → 加 [CLS] → 自注意力交互 → 编码器表征 → 分类头。只要能逐步解释每一个箭头，ViT 就不再是一句抽象的“Transformer 用在图像上”。

## 六、为什么 Patch 大小会影响速度与细节？

ViT 有一个非常重要的工程取舍：**Patch 越小，token 越多；token 越多，全局注意力通常越贵。**

仍以 $224\times224$ 图像为例：

| Patch 边长 | Patch 网格 | Patch token 数 | 加 [CLS] 后序列长度 |
| --- | --- | ---: | ---: |
| 32 | $7\times7$ | 49 | 50 |
| 16 | $14\times14$ | 196 | 197 |
| 8 | $28\times28$ | 784 | 785 |

若只看一个注意力头的分数矩阵，元素数是序列长度的平方。Patch 从 16 缩小到 8 后：

$$
\frac{785^2}{197^2}
=\frac{616225}{38809}
\approx15.88
$$

因此，在这个例子里，**注意力分数矩阵的元素数约增加 15.9 倍**。但这不是整个模型运行时间或显存一定增加 15.9 倍：真实开销还包括线性投影、MLP、批次大小、隐藏维度、实现优化和硬件特性。

从复杂度看，标准全局注意力计算 $QK^\top$ 和加权求和的主要运算量随 token 数 $N$ 近似按 $O(N^2D)$ 增长；这里把 [CLS] 的常数差异略去，$D$ 为隐藏维度。

这就是为什么高分辨率图像、细小文字和密集文档会给视觉 Transformer 带来额外挑战：想保留更多局部细节，就可能需要更多 token 或其他更高效的架构设计。

## 七、ViT 与 CNN：不是谁彻底取代谁

| 比较维度 | CNN | 经典 ViT |
| --- | --- | --- |
| 基本处理单元 | 局部卷积窗口 | 图像 Patch token |
| 空间归纳偏置 | 局部性、权重共享很明确 | 主要通过 Patch 化、位置表示与训练学习空间关系 |
| 远距离交互 | 通过多层网络逐步扩大感受野 | 全局注意力可直接连接远处 token |
| 数据与预训练 | 局部先验在数据较少时常有优势 | 经典 ViT 在充分预训练下表现突出 |
| 计算瓶颈 | 与卷积核、通道、分辨率有关 | 全局注意力对 token 数呈平方级增长 |
| 典型改进方向 | 多尺度特征、轻量卷积等 | 分层窗口注意力、混合 CNN、稀疏注意力等 |

“ViT 能直接看全局”不等于它天然比 CNN 更准确；“CNN 擅长局部”也不等于 CNN 无法理解全局。现代视觉系统经常混合两者，选择取决于数据量、预训练资源、输入分辨率、延迟和任务。

尤其不要误以为“把图像切成 Patch”本身就是视觉理解：若 Patch 太粗，小字、细线、窄间隙可能在表示过程中变得难以辨认。实际系统还会使用更细粒度的特征、多尺度结构或专门的检测与识别模块。

## 八、放到 OCR 和文档理解中，ViT 有什么用？

在 OCR 场景里，目标通常不只是给整张图片分一个类别，而是找到文字、识别字符顺序、还原表格结构或理解页面含义。

**场景一：文本图像识别。** 例如输入一张裁剪好的单行文字图片，视觉编码器把图像转成特征序列；后续识别头可以采用 CTC 或自回归解码器来预测字符。ViT 可以担任视觉编码器，但**单独一个分类版 ViT 并不会自动输出整行文字**。模型还需要适合文字序列的输出结构和训练目标。

**场景二：文档版面分析。** 一张扫描件可能包含标题、正文、表格、页眉、印章和图片。Patch 之间的全局交互有助于建模跨区域关系，但仅靠图像特征并不能保证恢复正确阅读顺序或表格单元格。实际系统还可能结合检测框、二维位置、OCR 文本、图结构与多模态模型。

**场景三：细小字符与高分辨率页面。** 如果直接把一整页高分辨率扫描件缩成 $224\times224$，小字可能已经模糊。工程上常见的思路是分区域裁剪、提高输入分辨率、缩小 Patch、使用多尺度编码器，或先检测后识别。哪种方法更好，应以字符错误率（CER）、识别速度和实际文档数据为依据，而不是只看模型名称。

一个常见的完整 OCR 流程可以是：图像预处理 → 文本检测 → 文本区域裁剪 → 视觉编码器（CNN 或 ViT 等）→ 序列识别 → 版面或表格结构还原 → 结果校验。ViT 只是其中一种可选的视觉表征组件。

## 九、寓言和技术一一对应，但不能把比喻当成算法

| 寓言元素 | 对应技术 |
| --- | --- |
| 巨大的彩色玻璃窗 | 输入图像 |
| 切下的方形玻璃片 | Patch |
| 信使手中的短卡片 | Patch embedding |
| 卡片背面的位置印记 | 位置嵌入 |
| 信使带着问题交换线索 | Query、Key、Value 与自注意力 |
| 专门汇总全局的记录官 | [CLS] token |
| 多轮议会讨论 | 多层 Transformer 编码器 |
| 最终决定航道是否开放 | 下游分类头 |

这个比喻有三个边界。第一，真实模型没有会思考的信使，只有矩阵乘法、非线性函数和可训练参数。第二，注意力不等于因果解释：某个 Patch 的注意力权重大，不足以证明模型“因为它”作出判断。第三，[CLS] 不是所有视觉任务必备的角色；分割、检测和 OCR 可能需要对许多空间位置分别输出结果。

## 十、四个必须记住的知识点

1. **ViT 的入口是 Patch embedding**：把二维图像切块、展平并线性投影，形成 Transformer 能处理的 token 序列。
2. **位置不能凭空出现**：经典 ViT 要给 token 加入位置表示，否则单纯的自注意力缺乏原始二维位置的直接信息。
3. **核心交互仍是自注意力**：每个 Patch 能根据 Query 与 Key 的匹配，从其他 Patch 的 Value 中汇总信息；[CLS] 是分类任务中常用的全局汇总方式。
4. **Patch 大小是精度与成本的取舍**：更细的 Patch 有机会保留细节，却会显著增加 token 数和全局注意力成本。
