# 今日寓言：三道关卡的通行证

山国的旅人必须经过三道关口，才能领到通行证。第一关记录年龄和行程长度，算出一个分数；第二关只把符合条件的正分继续传递；第三关结合上一个分数得出最终建议。某天官员宣称“最后一关算错了”，可账本显示错事可能早发生在第一关：年龄被误填了一个数字。

新来的稽核官提出，每次处理都按固定顺序记录中间结果，不能一看最终错误就怪最后一位官员。他把旅人的原始信息、各关计算结果和最终输出连成一条清楚的链。这样，同样的输入经过同样规则就得到同样输出；只要某个旋钮改变，后面所有结果都需要重新计算。

他告诉城主：“这个流程现在只负责从入口走到出口。要教会它变好，还得知道出口到底离正确答案差了多少。”

# 概念揭示：前向传播 Forward Pass

## 一、解决的问题
神经网络包含很多层。我们必须明确一次预测时，输入怎样一步步变成最终输出；否则后面讨论损失函数、梯度和反向传播时，就不知道每个数字从何而来。

## 二、必要前置
**输入**是模型接收到的数字，例如两个像素特征；**权重与偏置**是线性层可调参数；**激活函数**处理线性层输出；**层**是连续的计算阶段。**中间值**是某一步得到、以后仍要用到的结果。

## 三、正式定义
前向传播是：在参数固定的情况下，从输入开始，按网络计算图的依赖顺序逐层计算所有中间激活和最终预测的过程。

假设输入为 \(x\)，第一层的权重和偏置为 \(W_1,b_1\)，输出 \(h\)；激活函数为 \(f\)；第二层权重偏置为 \(W_2,b_2\)，最终输出为 \(y\)。计算顺序为
\[
h=f(W_1x+b_1),\qquad y=W_2h+b_2.
\]
这里没有进行学习或参数更新，只是在计算一个结果。

## 四、手算一次
旅人的两个输入值为 \(x_1=2,x_2=3\)。第一层先算 \(z=2x_1-x_2+1=2\)。经过 ReLU：\(h=\max(0,2)=2\)。最后一层计算 \(y=3h-1=5\)。全过程是
\[
[2,3]\ \to\ z=2\ \to\ h=2\ \to\ y=5.
\]
若第一个输入从 2 变成 1，则 \(z=0\)，\(h=0\)，\(y=-1\)。上游的一个变化可以沿途影响最终答案。

## 五、与训练的关系
训练通常包含重复执行：前向传播得到预测；**损失函数**比较预测与正确答案；**反向传播**计算各参数会怎样影响损失；**优化器**根据这些信息改变参数。前向传播只是其中第一步。推理部署时通常只需要前向过程。

## 六、连接到 OCR
给 OCR 网络输入一张图像，前面的层提取边缘和笔画，中间层组合局部形状，后面的层输出字符分数或序列预测。不同模型的结构有所不同，但“数据按规则向输出方向流动”是共同骨架。

## 七、寓言映射与边界
旅人的资料是输入，三道关口是连续计算层，官员的规则是模型参数和函数，通行证是输出。局限是现实网络并不总是一条直链，还存在分支、跳跃连接等；“前向”指沿依赖关系求值，不必局限为从左到右画直线。

## 八、今天记住
1. 前向传播负责算预测，不负责改参数。
2. 每一步的中间值都有明确输入来源。
3. 上游变化可能影响所有下游计算。
4. 完整训练还需要损失、反向传播与优化器。
