# 今日寓言：裁缝的误差尺

王城有一位手艺精湛的裁缝，能根据客人的身高和肩宽预测衣服尺寸。最初他只知道每次剪出的衣服“看着差不多”，有人觉得袖子长，有人觉得腰太紧。师傅喊他再练十年，学徒却提出一个更朴素的问题：“每次都说好或不好，我们如何知道新一次到底进步了多少？”

他做了一把误差尺。客人需要 100 寸，裁缝裁了 110 寸，误差是 10；下一次裁了 103 寸，误差是 3。师傅说：“那若裁成 90 寸，你算出 -10，是不是表示比 110 更好？”学徒发现，把差直接相加会让正负抵消，于是决定把每个误差平方，再求平均。

学徒逐渐学会区分两件事：**裁缝已经预测出了什么**，以及**这个预测距离目标有多远**。只有第二件事能够稳定告诉他，调整剪刀和尺子以后究竟是在改进还是退步。

# 概念揭示：损失函数 Loss Function

## 一、它解决什么
神经网络前向传播会给出预测，但预测好坏需要可计算的标准。损失函数把“预测与目标相差多少”变成一个数字，用于训练时比较和改进参数。

## 二、前置概念
**预测值**是模型输出，记为 \(\hat y\)；**标签/目标值**是我们希望模型接近的正确答案，记为 \(y\)。**误差**是二者的差。**平方**把数字乘以自己，例如 \((-3)^2=9\)，可以避免正负差相互抵消。**平均**是总和除以样本个数。

## 三、正式定义与符号
损失函数 \(L\) 接收预测与目标，给出描述二者不一致程度的数值。最简单的回归损失之一是均方误差 MSE。先约定有 \(n\) 个样本，第 \(i\) 个真实值为 \(y_i\)，预测为 \(\hat y_i\)。对每个样本求差、平方、累加后除以 \(n\)：
\[
L_{\mathrm{MSE}}=\frac1n\sum_{i=1}^{n}(\hat y_i-y_i)^2.
\]
\(\sum\) 是求和，\(n\) 是样本个数，\(L\) 是最后的平均损失。平方让大的偏差受到更重惩罚。

## 四、手算完整例子
两位客人的真实袖长分别是 100、80；预测分别是 110、77。两项误差是 \(10,-3\)，平方后是 \(100,9\)。平均损失为
\[
L=(100+9)/2=54.5.
\]
裁缝改进后预测为 103、79，平方误差是 \(9,1\)，新损失 \((9+1)/2=5\)。数字从 54.5 降到 5，说明按照这个误差标准，预测更接近目标。

## 五、为什么损失能指导训练
损失函数只会打分，还不会告诉我们怎样调整权重。下一步需要用**导数**测量某个参数改变一点点会使损失增加还是降低，再用**梯度下降**选择更新方向。神经网络训练的常见流程是“预测 → 计算损失 → 计算梯度 → 调整参数”，不断重复。

## 六、AI 与 OCR
文字位置坐标预测可以使用适当的回归损失；字符分类常使用**交叉熵**，因为分类模型输出的是不同字符的分数或概率，和袖长这种连续数值的任务不同。选错损失会使模型优化与真实任务目标不一致，所以不是所有任务都要套 MSE。

## 七、寓言映射与局限
裁缝相当于模型；裁剪尺寸是预测；客人要求是标签；误差尺是损失函数；改进剪裁过程对应训练。局限是损失更低不自动等于现实效用更高：例如只关注平均误差可能忽视少数重要样本，所以还要看评估指标和测试集表现。

## 八、今日四个要点
1. 预测值与真实值不同，才产生训练信号。
2. 损失函数把不匹配转成数字。
3. MSE 是“每个误差平方后取平均”，不是万能损失。
4. 计算出损失不等于会优化；下一步必须理解导数和梯度。

**前置深化：** 平均与平方。**后续：** 导数、梯度下降。
