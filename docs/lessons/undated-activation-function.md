# 今日寓言：哨塔里的三扇门

城墙上有三座哨塔，塔里的人负责侦测远处的烽火。最开始，第一塔汇总东边信号后直接传给第二塔，第二塔也只把接到的数字按比例相加，第三塔照做。工匠很自豪：“无论多少塔，都能算得飞快。”

然而敌人学会在不同方向同时点火。两团弱光分别出现时不危险，组合出特定形状才代表进攻。哨塔只懂相加，看不出这样的组合。年轻守卫在每层传递前加了一道门：负分不通行，正分才继续传。不同来源的线索终于出现了复杂组合。有时门一关，传出去的信号就变成零；有时开门，数值原样通过。

工匠这才明白：不断增加只会加减乘的哨塔，不代表观察能力变复杂；真正改变的是每一层之间那道能让关系弯折的门。

# 概念揭示：激活函数与非线性

## 一、问题源头
把多层纯线性计算叠加，最终仍可化简为一次线性/仿射变换，难以描述复杂分类边界。神经网络因此在加权求和后使用**激活函数**，引入非线性。

## 二、先把名词说清
**函数**是给定输入、返回输出的规则，例如“输入 3，输出 9”的平方函数。**线性**在这里的直觉是加权求和与平移；严格地说，加偏置的 \(Wx+b\) 是仿射变换。**非线性**指不能简单等价为一个矩阵乘法加偏置的变换。

## 三、正式定义与公式
激活函数 \(f\) 是作用于神经元加权输入 \(z\) 的函数，输出 \(a=f(z)\)。\(z\) 是激活前分数，\(a\) 是传给下一层的值。

最常见的激活之一是 ReLU，规则非常朴素：正数留下，负数归零，0 仍为 0。符号 \(\max(0,z)\) 是在 0 与 \(z\) 中取较大值：
\[
\operatorname{ReLU}(z)=\max(0,z).
\]

## 四、亲手算一次
某层线性计算的三个输出是 \([-3,2,5]\)。逐个送入 ReLU：
\[
[-3,2,5]\ \longrightarrow\ [0,2,5].
\]
如果后一层用权重 \([1,1,1]\) 求和，激活后得到 \(0+2+5=7\)，激活前相加则是 \(-3+2+5=4\)。不同输入可能被关闭，使网络不再等同于连续的线性变换。

## 五、为什么这会提高表达能力
单个线性分类器的分界通常是一条直线或更高维的平面。ReLU 会在输入跨过 0 时改变计算规则，多个这样的单元组合，可以构造出复杂的分段线性关系。要注意：**非线性不是自动带来正确答案**；网络仍需通过训练选择合适权重。

## 六、AI 中的角色
CNN、MLP 和 Transformer 的部分子模块都用非线性变换。OCR 网络若只有矩阵乘法，就很难有效组合弯曲笔画与复杂字形。激活函数让不同层得以处理更丰富的模式。不同激活还有不同数值性质，后续才有必要比较 ReLU、Sigmoid、GELU 等。

## 七、寓言映射与局限
哨塔代表线性层，门代表激活函数；多种信号组合代表非线性特征。并不是神经元真的设有门，也不是 ReLU 会进行人为的“危险判断”；它只对数字执行确定规则。

## 八、记住四点
1. 激活函数放在线性变换之后，改变信号传递方式。
2. 非线性使多层网络不再容易化为单层线性计算。
3. ReLU 取 \(\max(0,z)\)，是最常见的简单例子。
4. 表达能力高不等于训练一定成功。
