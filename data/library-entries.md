# 文章库时间索引

`library-entries.json` 保存历史 Markdown 首次进入本仓库的提交 SHA 和提交时间（含时区），不代表原始创作时间，也不修改文章的 `date`、文件名或学习顺序。

首次恢复使用完整 Git 历史执行 `python scripts/backfill_library_dates.py`。脚本保留已有记录；没有证据的文章保持未知。Pages 构建只读取索引，不运行 Git 历史查询。

「最近入库」优先使用索引时间；后续每日文章未写入索引时，自动使用已有真实 `date`，在列表中明确标注「发布」而非「入库」。未知时间排在最后，同时间沿用课程顺序。日期按北京时间显示；日级发布日期不推断具体发布时刻。
